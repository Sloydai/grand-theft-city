GRAND THEFT OSLO
Created by Martin Truong · Sloyd
A GTA-style browser game in real central Oslo, with a flying Tesla Roadster.

HOW TO PLAY
1. Unzip this folder.
2. Mac: double-click "Start Game (Mac).command".
   The first time, macOS may block it: right-click the file > Open > Open.
   Windows: double-click "Start Game (Windows).bat".
   If Windows SmartScreen warns you: More info > Run anyway.
3. The game opens in your browser at http://localhost:8777. Loading takes about 20-60 seconds.
   Keep the black terminal window open while you play; close it to stop the game.

Use a recent Chrome, Edge or Safari on a computer with a graphics card.
Everything runs on your computer; no internet connection is needed.

CONTROLS
WASD          Move / drive
Mouse         Look around (click the game first)
Click         Shoot (on foot)
F             Enter, steal or exit a car
Shift         Sprint / fire the Roadster's thrusters
Space         Jump / handbrake
G             Fly or land (Tesla Roadster)
Space / C     Climb / descend while flying
H             Horn
M             Sound on/off
T             Skip two hours

The white Tesla Roadster is parked beside you at the start: walk up to it, press F, then G to fly.

CÁCH CHƠI
1. Giải nén thư mục này.
2. Mac: bấm đúp "Start Game (Mac).command".
   Lần đầu macOS có thể chặn: chuột phải vào file > Open > Open.
   Windows: bấm đúp "Start Game (Windows).bat".
   Nếu Windows SmartScreen cảnh báo: More info > Run anyway.
3. Game mở trong trình duyệt ở http://localhost:8777, tải mất khoảng 20-60 giây.
   Giữ cửa sổ terminal màu đen mở trong lúc chơi; đóng nó lại để tắt game.

Xe Tesla Roadster trắng đỗ ngay cạnh bạn: lại gần, bấm F để lên xe, bấm G để bay.
